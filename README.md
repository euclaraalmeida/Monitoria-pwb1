#  📚 Monitoria PWB1 - Fundamentos de HTML e CSS

Esse repositório de apoio da monitoria de **Programação Web 1 (PWB1)**, disciplina do curso de Engenharia de Software, focada em **Linguagens de Marcação**.

##  Sobre a Monitoria

Eu sou a monitora de PWB1 do curso de engenharia de software do ifpb e criei este material pensando especialmente nos alunos que estão tendo o primeiro contato com o desenvolvimento web. O objetivo deste repositório é ajudar a superar as dificuldades iniciais com a estruturação (HTML) e estilização (CSS) de páginas.

## O que você vai encontrar aqui?

Este material reúne resumos teóricos e exemplos práticos para fixação do conteúdo:

### 1. Conceitos Iniciais
* **Introdução ao CSS:** Explicação sobre seletores (`.class`, `#id`), tipos de inserção de CSS (inline, interno e externo) e propriedades básicas.
* **Box Model:** Entenda visualmente como funcionam as Margens, Bordas e Padding de um elemento.

### 2. Layout e Posicionamento
* **Flexbox:** Exemplos de alinhamento em uma dimensão (linhas ou colunas), perfeito para organizar itens dentro de um container.
* **CSS Grid:** Exemplos de layout bidimensional (linhas e colunas), ideal para estruturar a página inteira.
* **Display Inline-Block:** Métodos clássicos de posicionamento de elementos lado a lado.

### 3. Responsividade
* **Mobile First:** O conceito de criar estilos para celulares primeiro e expandir para telas maiores.
* **Media Queries:** Como adaptar o layout para diferentes tamanhos de tela (Tablets e Desktop).

##  Como estudar com este repositório

1.  **Clone ou baixe** este repositório.
2.  Abra os arquivos `index.html` no seu navegador para ver o resultado visual.
3.  Abra os arquivos `.css` e `.md` no seu editor de código (como o VS Code).
    * 💡 **Dica:** Os arquivos contêm muitos comentários explicativos (ex: no `grid-flex/style.css`) detalhando o que cada comando faz. Experimente descomentar algumas linhas para ver as mudanças em tempo real!
